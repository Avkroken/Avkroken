# Avkroken

Avkrokens samlade applikationsrepository.

## Apps

- `apps/portal` — avkroken.denied.se
- `apps/skvallerbyttan` — read-only observationslager och dashboard
- `apps/krosa-maja` — autentisering/OAuth
- `apps/jobb` — jobb- och automationsapplikation

Organisationsgemensam intern dokumentation ligger i `docs/organization/`.

Varje app behåller sin egen runtime-konfiguration, migrationshistorik och applikationsdokumentation under sin katalog.
