DRIFT & INSYN

Vad Avkroken ser

Operativ state ska i första hand komma från Skvallerbyttans normaliserade read-only modell, med freshness och täckning tydligt skilda från antagen komplett aktivitet.

GITHUB

Observerad state

CI, releases, säkerhet och annan providerstate kopplas via Skvallerbyttan där capability finns.

CLOUDFLARE

Observerad state

Portalens grundlager introducerar ingen ny Cloudflare-providerklient eller permission.

FRESHNESS

Synlig täckning

Senaste lyckade observation, cacheläge och källtäckning ska visas när integrationen kopplas in.

Dataintegration ligger i separat PR. Den här foundation-PR:n etablerar ytan och accessgränsen men fabricerar ingen driftstatus.
